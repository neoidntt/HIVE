# HIVE core dependencies.
#
# Lower bounds are deliberate, not decorative -- each one marks an API HIVE relies on:
#   scikit-image >=0.19  : `intensity_mean` / `axis_major_length` regionprops names.
#                          Below this they are `mean_intensity` / `major_axis_length`.
#   numpy        >=1.24  : stable NEP-50 promotion rules.
#   pandas       >=2.0   : consistent `to_csv`/`ExcelWriter` behaviour.
#
# Verified against the exact versions in requirements-lock.txt. For a reproducible
# analysis environment, install that file instead -- an unpinned scientific stack
# means a result you cannot reproduce in six months.

numpy>=1.24
scipy>=1.10
scikit-image>=0.19
pandas>=2.0
tifffile>=2023.1.1
imagecodecs>=2023.1.1      # decodes compressed TIFF variants tifffile alone cannot
matplotlib>=3.7            # colormaps for 3D rendering; Sholl plots
pillow>=9.5                # GIF encoding with a shared adaptive palette
plotly>=5.14               # interactive 3D mesh viewer, Sholl charts
openpyxl>=3.1              # multi-sheet Excel reports (CSV export needs nothing extra)

# --- Web app / API ---
streamlit>=1.32
fastapi>=0.100
uvicorn[standard]>=0.23
python-multipart>=0.0.6    # required by FastAPI for file uploads

# --- Testing ---
pytest>=7.4

# --- OPTIONAL: deep-learning segmentation -------------------------------------
# Large download (~2 GB with CUDA wheels) and slow on CPU. HIVE degrades cleanly
# without it: `--method cellpose` raises a clear ImportError, everything else works.
# Thresholding often beats Cellpose on connected tissue such as neuropil, which is
# what Cellpose was NOT trained on.
#   pip install cellpose torch torchvision
#
# torch also enables GPU acceleration (CUDA / Apple MPS) in hive.hardware. Note the
# measured reality: the CPU pipeline runs a 31 MB stack in ~1 s, so a GPU only pays
# off for large volumes or long GIF rotation sweeps. Memory is the real constraint.
